# GoTo SSH Manager - Homebrew Formula #

Homebrew formula for GoTo SSH Manager, a CLI tool to manage SSH connections.

## Installation ##

```bash
brew tap grafviktor/goto
brew trust grafviktor/goto # Only required for homebrew 6.0 and above
brew install --cask goto-ssh-manager
```

This installs the `gg` binary onto your system. Run it with:
```bash
gg
```
